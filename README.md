## Releasing

Releases are automated with [release-please](https://github.com/googleapis/release-please). Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `feat!:`); release-please keeps a release PR up to date on `main`, and merging it tags the release, publishes a GitHub release and publishes the package to npm.
